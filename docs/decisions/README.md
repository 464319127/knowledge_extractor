# 技术决策记录

本目录用于记录会对架构、运维、依赖、数据、安全或兼容性产生长期重要影响的决策。

## 命名规则

使用连续编号和简短的 kebab-case 标题：

`NNNN-short-title.md`

例如：`0001-storage-format.md`。

## 必需结构

```markdown
# NNNN：决策标题

日期：YYYY-MM-DD
状态：提议 | 已接受 | 已取代

## 背景

什么问题、约束或变化促成了这项决策？

## 决策

决定采用什么方案？

## 理由

为什么选择这个方案？必要时说明重要的备选方案。

## 影响

这项决策会让哪些事情变得更容易、更困难、成为必要条件或不再兼容？
```

不要通过改写已接受的记录来掩盖后续变化。应新增一条记录，将旧记录标记为“已取代”，并在两条记录之间互相链接。
