建立由 Git 管理、默认使用简体中文的持久项目知识，使后续工作能够根据仓库上下文继续进行。

## 已完成

- 添加 `AGENTS.md`，包含启动、知识维护、交接、决策记录、任务跟踪和信息卫生约定。
- 明确项目知识默认使用简体中文，不宜翻译的技术内容保留原文。

## 决策

- 项目知识按有效期和用途拆分：长期约定写入 `AGENTS.md`，里程碑状态写入本文件，重要技术决策写入 `docs/decisions/`，可执行的后续工作写入 `TODO.md`。这样可以保持启动上下文简洁，并避免重复记录细节。
- 项目知识默认使用简体中文，代码标识符、命令、路径、协议名及其他不宜翻译的内容保留原文，以兼顾可读性和技术准确性。
